# Adithya Rajesh — Portfolio v2

Neo-brutalist personal portfolio. React + Vite + GSAP, no other dependencies.

## Run it locally

```bash
npm install
npm run dev      # dev server, usually http://localhost:5173
npm run build    # production build → dist/
npm run preview  # serve the production build locally
```

## Editing content

**Everything you'd want to change lives in one file:** [`src/data/content.js`](src/data/content.js)

- `profile` — name, roles, email, GitHub/LinkedIn URLs, bio
- `projects` — shipped work (title, description, tech, links, accent color)
- `building` — the "Currently Building" roadmap cards; move a project up into `projects` the day it ships
- `skills` — category cards with CORE / LEARNING badges
- `stats`, `marqueeItems` — hero numbers and the scrolling strip

Colors, borders and shadows are CSS variables at the top of [`src/styles.css`](src/styles.css).

## Deploying — LIVE at https://adithya-portfolio-olive.vercel.app

Connected to Vercel via GitHub. **Every `git push` to `main` auto-deploys** — that's the whole workflow:

```bash
git add -A && git commit -m "what changed" && git push
```

Vercel Dashboard (vercel.com) → project → Deployments: every build is kept, so any deploy can be **rolled back instantly** with one click — nothing is ever irreversible.

## Structure

```
src/
  data/content.js      ← ALL content (edit this)
  components/          ← Nav, Hero, Work, Building, Marquee, About, Contact
  components/reveal.js ← GSAP scroll reveals (respects reduced motion)
  styles.css           ← neo-brutalist design system
public/
  favicon.svg
_legacy-v1/            ← the old design, kept for reference (safe to delete)
```

## Accessibility notes

- Full keyboard focus states (3px red outline)
- `prefers-reduced-motion`: all animation, marquees and scrambles disable
- Semantic landmarks (`header/main/section/footer`), aria labels on icon-only controls
- Mobile: hamburger menu, stacked layouts, no hover-dependent information
